# linearframework

This folder holds tutorials and information about the use of linearframework.py.

the intended flow through these documents is as follows:
- `Graph Tutorial.ipynb` which shows how to initialize graphs and their builtin capabilities
- `Steady-State and Transient Quantities tutorial.ipynb` which describes the calculation of steady states, moments of the first passage time distribution, splitting probabilities and `linear-framework-ii.pdf` for the mathematical expressions being calculated.
- `Generalized Aldous Shepp Demo.ipynb` and it's accompanying `A conjecture for the refinement of the Aldous-Shepp theorem.pdf` which demonstrates the use of linearframework.py to numerically test conjectures on linear framework graphs.
